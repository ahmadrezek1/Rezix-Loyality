# Rezix v0.8.4 – E-Mail-only Authentication

- Kein 2FA / kein Authenticator mehr.
- Admin bestätigt die hinterlegte E-Mail-Adresse einmalig per Resend-Link.
- Manager und Friseur bestätigen ihre E-Mail-Adresse einmalig über den bestehenden Verifizierungslink.
- Danach Anmeldung nur mit E-Mail + Passwort.
- Kunden bleiben beim bestehenden einmaligen E-Mail-OTP/Session-Flow.
- Aktive Sitzungen und Rate-Limits bleiben als Schutz bestehen.

Nach dem Update einmal `npm run db:migrate` ausführen.
