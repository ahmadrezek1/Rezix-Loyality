# Update von Rezix v0.3 auf v0.4

1. Projektdateien ersetzen / Git committen.
2. Lokal `.env.local` beibehalten.
3. Migration ausführen:

```bash
npm install
npm run db:migrate
```

4. Lokal testen:

```bash
npm run dev
```

5. Danach pushen:

```bash
git add .
git commit -m "Rezix v0.4 security roles audit"
git push
```

Vercel deployt automatisch. Die bestehende Datenbank bleibt erhalten; die Migration ergänzt nur Security-Tabellen.

## Prüfen

- `/manager/login` funktioniert
- `/friseur/login` funktioniert
