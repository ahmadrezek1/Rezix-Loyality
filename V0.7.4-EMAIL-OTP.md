# Rezix v0.7.4 – E-Mail OTP

Customer authentication now uses Resend e-mail OTP instead of Twilio/SMS.

Required production variables:

- `RESEND_API_KEY`
- `REZIX_EMAIL_FROM=Rezix <noreply@rezix.at>`
- `NEXT_PUBLIC_APP_URL=https://loyalty.rezix.at`

Run `npm run db:migrate` once after deployment preparation. The migration adds customer e-mail columns while preserving legacy phone data.

Twilio variables are no longer required for customer login.
