# Rezix v0.8.1 – QR Scanner

- QR scanning now uses `@zxing/browser` instead of relying on the native `BarcodeDetector` API.
- Designed to work on iPhone/Safari, Android/Chrome and desktop browsers with camera access.
- Uses the rear camera when available.
- Stops the camera immediately after a valid `RZX-XXXXXXXX` code is detected.
- Manual code entry remains available as a fallback.
- Customer session behavior remains: after first e-mail verification on the same device, the stored customer token opens the card without another OTP.
