# Rezix v0.8.0 – UX & Loyalty Customization

## Änderungen
- Neues Rezix Admin-Branding integriert.
- Kundenansicht vereinfacht: keine Datenschutz-Anfragen, kein Datenexport/Marketing-Center; nur notwendige AGB-/Datenschutz-Bestätigung bei Registrierung.
- Friseur-Konsole: Kamera-Button, Kamera-Berechtigung, QR-Erkennung per Browser BarcodeDetector mit manueller Eingabe als Fallback.
- Manager: Datenschutz-Anfragen, Sitzungs-/Sicherheitsprotokoll und Audit-Ansicht aus der sichtbaren Oberfläche entfernt.
- Zahlungsanbieter wird in der Manager-Oberfläche nicht namentlich erwähnt; Tarif & Abrechnung bleibt funktional.
- Manager kann Stempelziel, Belohnung, Kartentitel, Untertitel, Akzentfarbe, Stempelform, Logo und Stempelbild anpassen.
- Live-Vorschau der Kundenkarte im Manager Dashboard.
- Tariflimits: Starter 1 Friseur, Professional 5 Friseure, Business 100 Friseure. Trial: 1 Friseur.
- Jahresauswahl aus der sichtbaren Tarifoberfläche entfernt.
- POLICY_VERSION Export ergänzt (Build-Fix für Email OTP).

## Update
```bash
npm install
npm run db:migrate
npm run build
```
Danach committen und auf `main` pushen.

## Kamera
Kamerazugriff funktioniert nur in sicheren Kontexten (HTTPS oder localhost). Beim ersten Öffnen muss der Friseur die Browser-Berechtigung erlauben. Wenn der Browser die BarcodeDetector-API nicht unterstützt, bleibt die manuelle Code-Eingabe verfügbar.
