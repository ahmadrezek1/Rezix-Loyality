# Rezix v0.8.4.1 cleanup

v0.8.4 removed Authenticator/TOTP 2FA. When a ZIP is copied over an older Windows project, files deleted by the new release can remain in the old repository.

Run once after copying this release over an older Rezix checkout:

```bash
npm run cleanup:obsolete
npm run build
```

This removes the obsolete 2FA routes/pages and TOTP components. Manager/Friseur use one-time email verification and Admin uses one-time email verification before normal password login.
