# Rezix v0.7.3 – Admin Salon Overview

- Admin listet nur echte Multi-Salon-Einträge; der historische Legacy-Datensatz `main` wird nicht mehr im Admin als Salon dargestellt.
- Kunden bleiben ausschließlich im jeweiligen Manager-Dashboard sichtbar.
- Jeder Salon zeigt jetzt Aktiv/Gesperrt, Tarif (Free Trial / Starter / Professional / Business), Subscription-Status und verbleibende Trial-Tage.
- Systemübersicht zeigt Salon-Anzahl, aktive Salons und laufende Trials.
- Neue Salons erhalten ab dieser Version 3 Tage Trial statt 14 Tage. Bestehende Trial-Enddaten werden nicht rückwirkend gekürzt.
