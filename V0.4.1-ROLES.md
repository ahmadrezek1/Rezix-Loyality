# Rezix v0.4.1 – Rollenmodell

Das Rollenmodell wurde auf vier klare Begriffe reduziert:

- **Admin** – globale Rezix-Verwaltung
- **Manager** – verwaltet genau einen Salon, Branding, Kundenübersicht und Friseur-Zugänge
- **Friseur** – darf Kunden erfassen und Stempel vergeben, aber keine Salon-/Admin-Einstellungen verwalten
- **Kunde** – sieht ausschließlich die eigene Loyalty-Karte des Salons

## Geänderte Bereiche

- Manager: `/manager/login` und `/manager`
- Friseur: `/friseur/login` und `/friseur`
- Alte Owner-Rolle wird bei Migration zu `manager`.
- Alte Staff-Rolle wird bei Migration zu `friseur`.
- Audit-Einträge `customer` werden zu `kunde`.

## Update bestehender Datenbank

```bash
npm run db:migrate
```

Danach Anwendung neu starten/deployen.
